묻힌 태양 프롬프트북

무료 기간 동안 뽑을 모든 일러스트와 모션의 영어 프롬프트입니다. 복사를 누르면 스타일 문구까지 합쳐진 완성 프롬프트가 복사됩니다. P1부터 뽑으세요. 체크 기록은 이 기기에만 저장됩니다.

남은 기간 작전 (P1만 이 순서로)
  1. 스타일 기준 4장(스타일 기준 탭)을 먼저 20~40장 뽑아 고르세요. 이후 모든 생성에 레퍼런스로 넣습니다.
  2. 영웅 16명 스프라이트 앞(영웅 탭) → 각자의 초상, 턴어라운드, 그림자 모습.
  3. 적·보스 스틸 → 장면 → 전투맵 → 타일 → 소품.
  4. UI·아이콘·카드 틀 → 사건 카드 그림(에1·2가 P1).
  5. 영상은 마지막에 몰아서: 영웅 P1 모션(대기, 걷기, 기본 공격, 등갓 열기) → 이펙트 P1 → 시네마틱 P1.
  6. 매일 밤 전부 다운로드. 파일 이름은 항목 ID 그대로(예: KN-F-S_v3.png).
  7. 상업적 이용이 가능한지 약관을 꼭 확인하세요.
그림이 AI 티 나지 않게
  • 모든 프롬프트에 나이, 체형, 피부색, 흉터, 수선한 옷이 들어 있습니다. 지우지 마세요.
  • 네거티브에 상투형(파란 로브, 뾰족 모자, 흰 수염, 대칭 얼굴, 영웅 포즈, 빛나는 눈과 룬, 반짝이)이 들어 있습니다. 네거티브 칸이 없는 모델이면 프롬프트 끝에 "Avoid: …"로 붙여 넣으세요.
  • 같은 프롬프트로 4장씩 뽑고, 가장 덜 예쁘고 가장 사람 같은 것을 고르세요.
  • 얼굴이 비슷해지면 다른 영웅의 결과를 레퍼런스로 넣지 마세요. 영웅마다 자기 스프라이트만 레퍼런스로.
  • 그림자 없는 화면: 이 세계에서는 볕돌 빛이 닿는 곳이 아니면 아무것도 바닥에 그림자를 드리우지 않습니다. 결과에 바닥 그림자가 있으면 다시 뽑거나 지우세요.
  • 금빛은 볕돌뿐: 볕쇠는 검붉은 쇠, 보통 불은 창백한 회백색입니다.
모션 규칙과 검수표 (칼이 사라지거나 팔이 떨어지지 않게)
  • 반드시 이미지→영상으로 만드세요. 승인된 스프라이트(ID가 적혀 있음)를 시작 프레임으로 넣습니다.
  • 한 클립에 동작 하나, 3~5초. 움직임 세기 설정이 있으면 낮게.
  • 대기·걷기는 끝 프레임에 시작 프레임과 같은 이미지를 넣을 수 있으면 넣으세요. 루프가 깔끔해집니다.
  • 프롬프트마다 무기 규칙이 들어 있습니다(예: "검은 오른손, 방패는 왼팔, 팔이 방패를 뚫지 않음"). 지우지 마세요.
  • 검수표 — 받은 영상을 한 프레임씩 넘겨 보세요:
    1. 무기가 처음부터 끝까지 같은 손에, 같은 모양으로 있는가
    2. 방패 밖으로 팔이 튀어나오거나 방패를 뚫지 않는가
    3. 팔다리가 몸에서 떨어지거나 하나 더 생기지 않는가
    4. 손가락 수, 얼굴, 옷이 바뀌지 않는가
    5. 발이 미끄러지거나 떠오르지 않는가
    6. 카메라와 배경이 그대로인가
    7. 루프는 끝과 처음이 이어지는가
    하나라도 걸리면 버리고 다시 뽑으세요.
  • 정직한 조언: AI 영상은 게임 안에서 반복 재생될 전투 모션에는 오류가 잘 생깁니다. 최종 게임 모션은 리깅 파츠 시트(영웅 탭의 R 항목)로 2D 뼈대 애니메이션을 만드는 것이 가장 안전합니다. AI 영상은 시네마틱, 이펙트, 배경 모션, 초상 말하기, 그리고 모션 참고용으로 쓰세요.
  • 게임용 처리: 회색 배경 제거 → 초당 12프레임으로 잘라 스프라이트 시트 → 발 위치를 같은 기준점에 맞추기.
보드게임 실물을 위한 규격
  • 카드는 63×88mm(포커 규격). 2:3으로 뽑고 가장자리 3mm를 잘라낼 여유를 두세요. 중요한 것은 가운데 80%에.
  • 인쇄는 300dpi가 필요합니다. 가장 높은 해상도로 뽑고 나중에 업스케일.
  • 턴어라운드와 피규어 원형 시트는 미니어처 조각가에게 넘길 자료입니다.
  • 아이콘은 48px로 줄여 알아볼 수 있는지, 흑백으로 바꿔도 구분되는지 확인하세요(색약 대비).
