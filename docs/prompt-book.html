마지막 성화 프롬프트북

힉스필드 무료 3일 동안 쓸 프롬프트 모음입니다. 각 항목의 복사를 누르면 스타일 문구까지 합쳐진 완성 프롬프트가 복사됩니다. 생성을 마친 항목은 체크해 두세요. 체크 기록은 이 기기에만 저장됩니다.

세계관은 임시로 A안 「꺼져가는 등불」입니다. 태양이 사라진 지 100년, 마지막 성화를 등불에 나눠 든 순례자들이 어둠 속을 걷습니다. 어둠의 것들은 빛에 끌립니다.

3일 일정

1일차 · 스타일 고정 → 주인공 → 적

처음 1~2시간은 스타일 테스트만 합니다. 기사, 나방 떼, 성당 배경 세 가지를 20~40장 뽑아서 기준 이미지 3~5장을 고르세요. 이후 모든 생성에 이 기준 이미지를 레퍼런스로 넣습니다. 다음으로 주인공 전신 → 초상 → 타락 버전, 그다음 일반 적.

2일차 · 보스 → 배경 → 지도 → 오브젝트 → 카드 일러스트

물량이 가장 많은 날입니다. 카드 일러스트는 장당 4장씩 뽑고 바로 고르세요.

3일차 · 아이콘 → UI 프레임 → 이펙트 → 영상

영상 크레딧은 마지막 날 몰아서 씁니다. 타이틀 루프, 주인공 대기 루프, 이펙트 루프 순서. 남은 시간에는 빈 곳을 다시 뽑습니다.

시작 전에 꼭

  • 상업적 이용 조건 확인. 무료 체험으로 만든 이미지를 게임에 써도 되는지 힉스필드 약관을 먼저 보세요. 안 된다면 이번 3일은 컨셉/프로토타입용으로 생각해야 합니다.
  • 매일 밤 전부 다운로드. 체험이 끝나면 생성 기록에 접근하지 못할 수 있습니다. 파일명은 항목 ID로 맞추세요(예: H02_v3.png).
  • 투명 배경은 나오지 않습니다. 캐릭터·적·오브젝트는 단색 회색 배경으로 뽑고, 배경 제거는 나중에 무료 도구로 일괄 처리합니다. 이펙트는 순흑 배경으로 뽑아 게임에서 가산(Add) 블렌드로 쓰면 검은색이 사라집니다.
  • 글자는 넣지 않습니다. AI는 글자를 망칩니다. 카드 이름·수치·로고 글자는 게임 안에서 텍스트로 얹습니다.
  • 레퍼런스 이미지를 받는 모델을 쓰세요. 같은 캐릭터를 여러 장 뽑을 때(초상, 타락 버전, 카드 일러스트) 기준 이미지를 넣어야 얼굴과 복장이 유지됩니다. 주황 테두리의 REF 표시가 붙은 항목입니다.
  • 가장 높은 해상도로. 업스케일은 나중에 해도 되지만, 작게 뽑은 디테일은 되살리지 못합니다.
